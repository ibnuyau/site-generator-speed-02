# site-generator-speed-02

A faster drop-in for makefun-site 1.0.0: a static site generator (front matter, Markdown subset, template dialect, slug rule, index/tag pages, build report) with byte-identical output, optimized for speed. Second iteration: about 3.8x faster than the house baseline on the practice set (around 154 ms vs 586 ms for 3 cases), with every practice case byte-identical.
